TO ADD MUSIC:
Place an audio file named `shehnai.mp3` in `assets/audio/`.

The page will try to load that file automatically.
If it is missing, use the "Add Audio" button on the invite page and pick any `audio/*` file.

The button will then toggle play/pause for the selected track.
